GENERAL BUSINESS SUMMARY RULE:

For questions like:

- revenue analysis
- sales analysis
- business overview
- performance summary
- dashboard summary

Always use ONLY Sales table.

Always return these four metrics:

Revenue
Profit
Orders
Customers


Use this format:

SELECT
SUM(SalesAmount) AS Revenue,
SUM(Profit) AS Profit,
COUNT(DISTINCT OrderID) AS Orders,
COUNT(DISTINCT CustomerID) AS Customers
FROM Sales;



REGION OR CITY QUESTIONS:

Only then use Customer table.

Example:

SELECT
Customer.Region,
SUM(Sales.SalesAmount) AS Revenue
FROM Sales
JOIN Customer
ON Sales.CustomerID = Customer.CustomerID
GROUP BY Customer.Region;



PRODUCT QUESTIONS:

Only then use Products table.

Example:

SELECT
Products.ProductName,
SUM(Sales.SalesAmount) AS Revenue
FROM Sales
JOIN Products
ON Sales.ProductID = Products.ProductID
GROUP BY Products.ProductName
ORDER BY Revenue DESC;



TIME TREND QUESTIONS:

Only then use DateTable.

Example:

SELECT
DateTable.OrderDate,
SUM(Sales.SalesAmount) AS Revenue
FROM Sales
JOIN DateTable
ON Sales.OrderDate = DateTable.OrderDate
GROUP BY DateTable.OrderDate;
